You do not have to tell Sophia to remember every useful fact. When enabled, idle dreaming reviews delivered conversations and proposes memories or procedural lessons. It preserves source references and audience restrictions. It is background model work and appears in usage accounting.

## Correct what it remembers



> **You**: I prefer short answers unless I ask for a breakdown.
>
> **Sophia**: I'll keep answers short by default.
>
> **You, later**: What do you remember about how I like explanations?
>
> **Sophia**: Short by default, with more detail when you ask.
>
> **You**: Update that: include an example when explaining code.

Sophia can search, explicitly save, revise and forget memories. Portable presentation preferences follow your account. Ordinary private facts retain their original audience. Forgetting uses tombstones so an idle job cannot immediately reconstruct the deleted memory from the same source.

Operators use `/memories` to review quarantined legacy content and explicitly adopt eligible records. Legacy memories do not automatically become public after migration.

## A skill saves a method

A skill describes how to do a repeatable task. It has a version, scope and source history. Sophia can find, load, save, assess and delete skills. Operator review is available through `/skills`.



> **You**: This event comparison worked well. Save the method for next month.
>
> **Sophia**: I'll save a method that checks dates, deduplicates announcements, compares attendance, and cites the final decisions.
>
> **You, later**: Use that event comparison method for August.

Dream-derived skills require assessment tied to the exact method and a completed owned task before promotion. Imported or uncertain methods remain quarantined or private drafts. A skill is procedural guidance, not permission to perform its actions.

The older workflow tools remain compatible entrypoints into the skill system. They do not run a separate workflow engine. See [skills architecture](../../build/skills/).
